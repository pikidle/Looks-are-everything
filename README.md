# 오늘의 인연

입력한 정보를 바탕으로 잘 맞는 상대를 추천하고, **왜 그 사람을 추천했는지** 점수와 로직을 함께 보여주는 소개팅 매칭 데모입니다.
서버나 빌드 과정 없이 HTML/CSS/JS만으로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일을 올립니다.
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<아이디>/<저장소>.git
   git push -u origin main
   ```
3. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 지정하고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/`에서 확인할 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 시작 화면, 질문 화면(한 화면에 한 질문), 진행도 게이지, 결과 영역 |
| `style.css` | 스타일 (라이트/다크 모드) |
| `constants.js` | 선택지(지역, 태그, 라이프스타일)와 **점수 배점** |
| `candidates.js` | 가상 후보 100명 (시드 고정, 항상 같은 데이터) |
| `app.js` | 필터 → 점수 계산 → 결과/로직 설명 렌더링 |

## 매칭 로직

**1. 양방향 필터**: 하나라도 어긋나면 후보에서 제외
- 성별: 서로가 원하는 성별에 맞아야 함
- 나이: 서로가 원하는 나이 범위 안에 있어야 함
- 지역: 한 명이라도 '같은 시·도만'을 골랐다면 같은 지역이어야 함

**2. 점수 (100점 만점)**

| 항목 | 배점 | 계산 |
|---|---|---|
| 라이프스타일 | 50 | 5문항 × 10점 (같음 10 / 한 칸 차이 5 / 두 칸 차이 0) |
| 관심사 | 35 | 희귀도 가중 다이스 계수 × 35 |
| 지역 | 10 | 같은 시·도면 10점 |
| MBTI | 5 | E/I 다름 2, N/S 같음 2, T/F 같음 1 (둘 다 입력 시) |

관심사 점수:

```
희귀도(태그) = ln((후보 수 + 1) / (그 태그를 고른 후보 수 + 1)) + 1
관심사 점수 = 2 × Σ희귀도(겹친 태그) / (Σ희귀도(내 태그) + Σ희귀도(상대 태그)) × 35
```

- 다이스 계수는 양쪽이 고른 태그 수로 나누기 때문에, 태그를 많이 골라도 점수가 부풀려지지 않습니다.
- 드문 태그가 겹칠수록 더 높은 점수를 받습니다.

**3. 정렬**: 총점 순으로 상위 5명 추천. 사진, 자기소개, 이상형은 점수에 반영하지 않고 보여주기만 합니다.

## 사진

- 프로필 사진은 필수 항목입니다.
- 내 사진은 브라우저 안에서만 쓰이며 서버로 업로드되지 않습니다. (JPG/PNG/WebP/GIF, 10MB 이하)
- 가상 후보는 사진 대신 이름 아바타로 표시됩니다. 후보 사진을 쓰려면 `photos/` 폴더에 이미지를 넣고 `candidates.js`의 `photo` 값에 경로(예: `'photos/1.jpg'`)를 지정하세요. 실제 인물 사진은 본인 동의를 받은 것만 사용해야 합니다.

배점은 `constants.js`의 `WEIGHTS`에서 바꿀 수 있고, 화면의 로직 설명도 함께 바뀝니다.
